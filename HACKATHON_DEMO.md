# EarthSignal hackathon demo script

Target length: 2–3 minutes.

1. **Problem (20 seconds):** Visible dumping can go undocumented or lack consistent evidence.
2. **Submit (40 seconds):** Upload a safe sample photo, choose a category, enter a public landmark, and tap a point on the map.
3. **Map (20 seconds):** Show the shared report pin and open its popup.
4. **Evidence (30 seconds):** Download the evidence summary and explain that it records the reporter's claims without presenting them as verified facts.
5. **Workflow (20 seconds):** Show submitted/review/resolved states. Moderator changes require project-member access.
6. **AI (30 seconds):** If the provider is configured, run AI analysis and explain that it describes visible content only and can be wrong.
7. **Open source (20 seconds):** Show the MIT license, README, and contribution guide.

## Before presenting

- Set project visibility to public if judges need direct access.
- Test the public URL in a private browser.
- Configure the AI provider and test one real image analysis.
- Test report submission from a second browser/device to verify shared database behavior.
- Use a sample report clearly marked as a demo, then remove it if it is not intended to remain public.
- Do not claim an authority received a report unless an actual integration submitted it.
- If the challenge requires an open-weight AI core, add and test an open-weight model before claiming that requirement is met.
