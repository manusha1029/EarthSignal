# Contributing to EarthSignal

Thanks for helping improve EarthSignal.

## Good first contributions

- Improve accessibility and mobile usability
- Add tests for report validation and duplicate detection
- Improve map marker clustering
- Add image similarity for duplicate suggestions
- Add an open-weight vision model option and document its license
- Add report export and moderation workflows
- Improve privacy, retention, and abuse-prevention controls

## Workflow

1. Open an issue describing the problem or proposed change.
2. Fork the repository and create a focused branch.
3. Keep changes small and explain the user-facing effect.
4. Test report creation, map pins, status changes, and evidence-summary export.
5. Submit a pull request with screenshots for visual changes.

Do not include real personal data, private addresses, faces, or unverified accusations in demo fixtures. Never commit provider credentials or secrets.
